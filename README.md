# mckoy-labs/homebrew-tap

Homebrew formulae for [SpotAgentIQ](https://github.com/mckoy-labs/spotagentiq):
human approval and a tamper-evident audit log for AI agent tool calls.

```sh
brew install mckoy-labs/tap/spotagentiq
spotagentiq demo
```

Formulae here are generated by the release workflow in the main repository.
Please open issues there, not here.
